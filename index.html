Fits & Dreams — Viability Matrices
Two diagnostics · one geometry

Students arrive different. Institutions must respond differently.

Both frameworks plot on the same plane: two axes, four quadrants, one point whose position is an estimate rather than a verdict. Run either one. The point comes back as an ellipse, because the width of the ellipse is part of the finding.

Where the two frameworks meet

An institution's quadrant determines which of the four learning environments it can run honestly, and each environment is built to serve a particular student type. So the institutional result ends where the student one begins: with a plain statement of which students this institution is actually equipped to serve, and which it would be taking money from under false pretences.

Both instruments are provisional. The student assessment is self-report and takes cognitive proxies at face value; it is not clinical, and it measures nothing about a person's worth. The institutional assessment mixes public financial data with judgments the user supplies about their own institution, and is only as honest as those answers. Nothing is stored. Everything runs in this browser tab and disappears when you close it.

Before you start

This is a self-report developmental assessment, not a clinical test, an IQ test, or an admissions instrument. It estimates where someone is right now on two dimensions and describes what kind of environment tends to help from there.

Results are approximate and meant for reflection. They describe a current state, not a fixed trait, and the same person can land in a different quadrant a year from now.

You can skip any question. Skipping costs precision, not access — the estimate widens and says so.

Nothing is stored or transmitted except, if a key is configured, the anonymous summary sent to write the interpretation.

Pick a length

Both forms cover the same eight dimensions of developmental readiness. The full form asks four questions per dimension instead of two, which narrows the estimate.

Academic proxy

This stands in, roughly, for the horizontal axis. A test score is noisy at the individual level and says nothing about creativity, judgment, or wisdom — it's used here only because it's the proxy most people already have a number for.

Without a score the estimate leans on coursework and self-description, and the horizontal uncertainty widens accordingly.

Developmental readiness

Answer as you actually are, not as you'd like to be. There are no correct answers, and no scored total is reported — only bands.

Place an institution

Two axes. Resources compresses the five forms of institutional capital into one blunt metric. Mission integrity asks whether that capital gets deployed in service of a stated purpose — a genuinely independent question, since a wealthy institution can drift more easily than a poor one, wealth having removed the discipline scarcity otherwise imposes.

Axis 1 — Resources, as five capitals

Financial capital is the one form public data can reach. Leave anything blank that you don't know; blanks are dropped from the estimate and widen the ellipse rather than counting as zero.

The other four capitals

These aren't measurable from outside, so they're your judgment — 1 is thin, 5 is deep. Each carries the same weight as the financial block.

Axis 2 — Mission integrity

Not whether the mission is admirable. Whether decisions track it.

With an API key configured, this text is read for the gap between stated purpose and revealed priority, and can move the mission-integrity estimate by a small amount in either direction. Without one, only the questions above count.

Setup

Everything here works without any keys — placement, scoring, cross-walks, and the written interpretation all run on deterministic rules in this file. Keys add two things: live public data for institutions, and an interpretation composed by Claude rather than assembled from templates.

Held in memory for this tab only and sent directly to api.anthropic.com from your browser. Never saved to disk, never sent anywhere else. If this page is running inside Claude, leave it blank — calls work without it.

For College Scorecard enrolment-trend lookups. Free and instant at api.data.gov/signup. DEMO_KEY is used if blank and works for a handful of calls before it rate-limits. The ProPublica 990 layer needs no key.

Fallback behaviour

If a lookup fails — no key, no network, a captive portal — the institution falls back to a built-in snapshot covering 23 New England institutions drawn from thomasmennella/higheredanalysis, and then to whatever you type in. Every displayed value is tagged live stored or entered, so provenance is never ambiguous.
